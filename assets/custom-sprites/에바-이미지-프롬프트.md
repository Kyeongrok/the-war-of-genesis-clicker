# 에바 빠진 모션 이미지 프롬프트

사용자 그림 30000 에바(`30000_에바.json`)에 아직 없는 동작을 AI 그림 도구로 받기 위한 프롬프트다.
받은 시트는 아래 **파일 이름** 그대로 `src/에바/` 에 넣고, 편집기 「모션 > 사용자 그림 만들기」에서 에바를 열어 시트를 더한다.

## 지금 있는 동작과 빠진 동작

모션 번호 = 동작 × 3 + 방향(0 뒷모습 · 1 옆모습 · 2 앞모습). 그 동작이 없으면 게임은 **서기로 대신**한다. 그래서 지금 에바는 맞아도, 기술을 써도 그냥 서 있다.

| 동작 | 뜻 | 지금 | 게임이 부르는 자리 |
|---|---|---|---|
| 0 | 서기 | 있음 (`stand.png`) | |
| 1 | 걷기 | 있음 (`sheet.png`) | |
| 8 | 베기 | 있음 (`attack.png`) | 기본공격 5 → **8** → 24 |
| 13 · 14 | 연속 베기 2 · 3타 | 있음 (`combo.png`) | |
| **2** | 맞음 · 죽음 | **없음** | 맞음 15틱 한 번, 죽음 21틱 (전투용 인물 199명 모두 있음) |
| **5** | 공격 준비 | **없음** | 기본공격 첫 단계, 기술 준비 5 → 7 |
| **24** | 공격 후 복귀 | **없음** | 기본공격 끝 단계 |
| **6** | 시전 자세 | **없음** | 마법 · 기술 준비 6 → 15, 필살기 전주, 얼음 굳음 |
| **15** | 시전 발동 | **없음** | 6 다음 |
| **7** | 기 모으기 | **없음** | 기술 준비 5 → 7 |
| 9 | 원거리 기본공격 | 없음 (2차) | 기본공격이 쏘기(work 6)인 인물만 |

26 · 27(필살기)은 인물마다 쓰는 자리가 달라 아직 뜻이 확정되지 않아 뺐다.

## 쓰는 법

- 모든 프롬프트 앞에 **공통 스타일**, 뒤에 **시트 꼴**을 붙인다.
- **`stand.png` 를 참고 이미지로 꼭 함께 넣는다.** 같은 몸 · 같은 색 · 같은 크기로 나오게 하는 데 이것이 가장 잘 듣는다. 첫 장이 잘 나오면 그것도 다음 시트의 참고로 쓴다.
- 줄은 **위에서부터 뒷모습 · 옆모습 · 앞모습** 순서, 옆모습은 **왼쪽을 보게** 한다(오른쪽은 게임이 뒤집어 쓴다). 줄마다 칸 수가 같아야 한다.
- 바탕은 마젠타 `#FF00FF` 단색. 그림자 · 바닥선 · 테두리 · 칸 선 없이.
- 글자 · 번호는 넣지 않는다.
- 우선순위: **1차** 먼저 받을 것(게임에서 바로 보인다) / **2차** 나중에.

### 공통 스타일

```
16-bit pixel art sprite sheet in the style of 1990s Korean tactical RPG battle sprites, crisp hard pixel edges, no anti-aliasing blur, limited palette. The character is a tall slender biomechanical giant robot: deep violet purple armor plates with thin orange seam lines, a narrow helmet head with one long forward-pointing horn on the forehead, a dark jaw with an orange-yellow V mark on the face and chest, tall bright lime-green shoulder pylons rising above the shoulders, lime-green accents on forearms, knees and feet, black joints, a short silver combat knife in the right hand. Exactly the same design, colors and body proportions as the attached reference sheet. No text, no numbers, no labels, no UI, no logos, no watermark.
```

### 시트 꼴

`{N}` 에 아래 표의 칸 수를 넣는다.

```
Sprite sheet layout: exactly 3 rows and {N} columns on an even invisible grid, one pose per cell, every cell the same size, the character the same height in every cell and centered in its cell with its feet on the same baseline. Row 1: seen from behind (back view). Row 2: side view facing left. Row 3: seen from the front. All three rows show the same animation frame by frame, left to right. Full body always visible with margin around it, nothing crosses into a neighbouring cell. Flat solid magenta #FF00FF background everywhere, no shadow, no floor, no grid lines, no borders.
```

## 3. 편집기에 넣을 때

「시트 추가」를 하면 줄 · 칸 · 바탕은 그림에서 찾아 채워진다. 줄의 방향이 뒷 · 옆 · 앞 순서인지 확인하고, 나머지 칸을 아래대로 채운다.

| 파일 이름 | 동작 | 기준 | 틱 | 맞는 장 | 소리 |
|---|---|---|---|---|---|
| `hit.png` | 2 | foot | 4 | | |
| `ready.png` | 5 | foot | 3 | | |
| `recover.png` | 24 | foot | 3 | | |
| `cast.png` | 6 | foot | 3 | | |
| `release.png` | 15 | foot | 3 | | |
| `charge.png` | 7 | foot | 5 | | |
| `shoot.png` | 9 | foot | 5 | 5 | 원하면 총소리 Snd 번호@4 |

틱 근거(원본 전투용 인물 199명 옆모습 평균, 분석-모션 §5): 맞음 3.9장 · 14.5틱(게임은 15틱으로 튼다), 공격 준비 5.9장 · 17.6틱, 복귀 5.3장 · 15.8틱, 시전 자세 1~2장, 시전 발동 2.6장 · 7.5틱, 기 모으기 12.9장 · 38.5틱.
맞음 · 죽음은 한 동작이라 `hit.png` 의 마지막 장이 쓰러질 때 잠깐 멈춰 보인다 — 무너지는 자세로 받아 두면 죽음도 어색하지 않다.

「만들고 미리보기」 → 「모션 보기」로 장 수 · 원점을 확인하고 「넣기」하면 `%APPDATA%\DuelDx\sprites` 의 에바가 바뀐다. 다 넣은 뒤 설정을 저장하면 다음에 이어 만들 수 있다.

### 잘 안 나올 때

- 줄마다 칸 수가 다르게 나오면: 프롬프트 끝에 `Count carefully: {N} poses in every row.` 를 더하고 다시 받는다. 편집기에서 칸 수를 줄여 잘라 써도 된다.
- 옆모습이 오른쪽을 보면: 그 줄만 좌우 뒤집어 넣는다.
- 몸 크기가 시트마다 다르면 괜찮다 — 만들기가 시트마다 키를 재 게임 키(100)로 맞춘다. 다만 한 시트 안에서는 같아야 한다.
- 마젠타가 그림 속 보라와 섞이면: 바탕을 `#00FF00` 초록으로 받고 편집기 바탕을 `key=00ff00` 으로 바꾼다(에바의 초록 부분이 같이 지워지면 `flood=5` 를 쓴다).
