# 구현 과제 돌리기

사용자는 옵시디안에 할 일을 적어 두고, 이 스킬로 **묻지 않고 끝까지** 돌리게 한다.
과제를 읽고 → 분석이 필요하면 에이전트에 맡기고 → 구현하고 → 화면을 건드리지 않고 검증하고 → 노트를 고치고 → **커밋·푸쉬**한다.

## 1. 과제 고르기

노트를 **매번 새로** 훑는다(`find 구현 분석과제 -name "*.md"`). 과제 꼴:

```
fg-10
맞는 효과 구현 해 적이건 아군이건
→ 분석: [[분석-전투]] · 2026-09-18
→ 구현: duel-dx — … · 상태: 완료 · 2026-09-18
```

`→ 구현:`(또는 분석과제면 `→ 결과:`) 줄에 `상태: 완료` 가 없으면 안 끝난 것이다. 설명이 바뀌었으면 다시 한다.
할 일이 여럿이면 사용자에게 한두 줄로 알리고 바로 시작한다 — **무엇부터 할지 묻지 않는다.**

## 2. 분석은 에이전트에, 구현은 내가

- 원본 규칙(수치·화면 구성·그림 번호)이 필요하면 [analyze-tasks](../analyze-tasks/SKILL.md) 규칙대로 **Agent 를 백그라운드로** 띄운다. 서로 다른 주제면 3~5개까지 같이 돌린다.
  프롬프트에 꼭 넣을 것: 게임 폴더는 읽기만 · 스크래치는 자기 폴더 · 결과는 `분석\분석-*.md` 절 + 과제 노트 `→ 분석:` 줄 · **어떤 Obs 파일을 `assets/` 에 넣어야 하는지** · 커밋 금지.
- 편집기 쪽 큰 구현은 에이전트에 맡겨도 된다(파일이 겹치지 않게 범위를 적어 준다). duel-dx 는 내가 한다.
- 에이전트를 기다리는 동안 손댈 수 있는 것(입력·창 자리·작은 버그)을 먼저 처리한다.

## 3. 구현할 때

- 원본 그림·소리는 `assets/`(ui·effects·sounds·bgm·characters·maps·data)에 넣고 게임 폴더에서 **복사만** 한다.
- 그림은 처음 쓸 때 푼다(시작이 느려진다). 자료를 다 읽기 전 조회는 "없음"으로 기억하지 않는다.
- 주석·UI 글은 한국어, 근거가 된 노트 절 이름과 DLL 주소를 함께 적는다.
- 가설로 넣은 값은 주석과 노트에 "가설"이라고 남긴다.

## 4. 검증 (사용자 화면을 절대 건드리지 않는다)

- 게임: `DUELDX_OFFSCREEN=1` 로 화면 밖(-8000)에 포커스 없이 띄우고, `PostMessage` 로 키·클릭을 넣고, `WM_APP_SNAPSHOT(0x8001)` 을 보내 `%TEMP%\dueldx_snapshot.png` 를 받아 눈으로 본다.
  `DUELDX_MUTE=1` 로 스피커를 막고, 소리를 확인할 때는 `AUDIOMIXER_SILENT=1` + `AUDIOMIXER_DUMP=<파일>` 로 섞인 소리를 받아 수치(RMS·무음 비율·튀는 순간)로 본다.
  테스트용 빌드는 `-o duel-dx/bin/ringtest`(사용자가 게임을 띄워 두면 bin/Debug 가 잠긴다). 도우미 스크립트: `…scratchpad\offtest.ps1`.
- 편집기: 창을 띄우는 대신 빌드한 `WarOfGenesis.Assets.dll` 을 pwsh 로 불러 **자료 수준**으로 맞춰 본다. 꼭 화면이 필요하면 `Left=-8000` + `RenderTargetBitmap`.
- 화면으로 확인 못 한 것은 보고에 그대로 적는다("빌드만 됨", "수치로만 확인").

## 5. 노트 고치기

과제 설명 바로 아래에 한 줄을 넣는다(있으면 고친다). 사용자가 쓴 줄은 건드리지 않는다.

```
→ 구현: duel-dx — 무엇을 어떻게 했는지 한 줄 · 상태: 완료|진행 중 · <날짜>
```

## 6. 커밋·푸쉬 (묻지 않는다)

검증이 끝난 덩어리마다:

```
git add -A && git commit && git push origin main
```

- 커밋 메시지는 영어 명령문 제목 + 무엇이 달라졌는지 몇 줄. 게임/편집기/도구가 섞이면 나눠 커밋한다.
- 태그 `vX.Y.0` 를 밀면 GitHub Actions 가 exe 두 개를 릴리즈한다. **릴리즈는 사용자가 말할 때만** 한다(커밋·푸쉬는 언제나 자동).
- 사용자가 편집기·게임을 띄워 두면 `bin` 이 잠겨 빌드가 실패한다 — 다른 폴더(`-o`)로 빌드해 확인하고, 그 사실을 보고한다.
